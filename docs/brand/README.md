# mobiCode brand

Use the supplied transparent PNG on a dark graphite or light solid background.
The cobalt/turquoise monogram combines a lowercase m with code brackets and a
terminal cursor. Keep clear space around it. The product name is **mobiCode**,
with a lowercase m and uppercase C.

Palette: graphite `#10151D`, cobalt blue, turquoise accent `#38D8BE`, off-white
`#EBF0F7`. Native typography uses Android's system sans-serif.

The original logo was generated with the built-in image-generation tool, then
copied unmodified into `docs/brand/mobiCode-logo.png` and the Android resources.
It is supplied as a raster asset, not an editable vector master.

Generation prompt:

> Create a premium original app logo symbol for a tablet coding IDE named
> mobiCode. Actual launcher icon foreground and GitHub brand mark; crisp, flat,
> geometric and vector-friendly, legible at 32 px. A distinctive lowercase m
> monogram constructed from two folded code-bracket strokes, with a tiny terminal
> cursor detail in the negative space. Compact balanced silhouette. Electric
> cobalt blue and turquoise, transparent background. No text, mockup, border,
> shadow, gradients, 3D, sparkles or circuit traces. Do not resemble the Visual
> Studio Code ribbon logo.
